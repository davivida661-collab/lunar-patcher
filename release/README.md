# LCQT2 Release (Linux portable)

This folder ships the portable Linux build of **Lunar Client Qt 2**.

Files inside `lcqt2-linux-portable.tar.gz`:
- `Lunar Client Qt` — the launcher injector (Rust)
- `agent.jar` — the Java agent (Kotlin bytecode patches)
- `gui.asar` — the Electron/Svelte GUI bundle

Extract anywhere and run `./Lunar Client Qt`.

See `README.md` at the repo root for usage instructions.
